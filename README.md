# AJAZZ Hub

Программа для настройки игровой мыши **AJAZZ AJ139 V2 MC**: DPI, частота опроса, кнопки, макросы, профили, напоминание о заряде и три стиля оформления.

## Скачать

Последняя версия — в разделе **[Releases](https://github.com/Scorpioom/ajazz-hub-releases/releases/latest)**: файл `AJAZZ-Hub-Setup.exe`.

Начиная с версии 1.4.3 программа обновляется сама: когда выходит новая версия, она показывает, что изменилось, и ставит обновление по кнопке «Обновить».
